# Python Data Structures Practice

## About
This repository contains my Python practice programs on Set, Tuple, and Dictionary. The purpose of this assignment is to understand Python data structures and their basic operations.

## Topics Covered

### 1. Set
- Creating a set
- Adding and removing elements
- Set operations
- Removing duplicate values

### 2. Tuple
- Creating a tuple
- Accessing elements using indexing
- Tuple slicing
- Using built-in tuple methods

### 3. Dictionary
- Creating a dictionary
- Accessing values using keys
- Adding and updating items
- Removing items
- Using dictionary methods

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the Python file in VS Code or another Python editor.
3. Run the program using Python 3.

## Learning Outcome
Through this practice, I learned how to create, access, update, and manipulate sets, tuples, and dictionaries in Python.
